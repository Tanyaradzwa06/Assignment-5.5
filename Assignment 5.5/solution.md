Design Choices
I used a consistent blue, teal, and white color palette to give the college club website a clean and professional appearance.
I used Arial typography with clear headings and readable paragraph sizes to improve readability.
I created a common navigation bar, reusable buttons, and card layouts to maintain consistency across all pages.
I used CSS variables, class selectors, and an external stylesheet to make the design easy to maintain and update.
I styled forms and tables for readability and added responsive CSS so the website works on smaller screens.
